# Oracle Fusion Technical Development

A private knowledge base and code repository for Oracle Fusion Cloud technical development.

## Technologies
- Oracle Fusion HCM, SCM, FIN, PPM and Payroll
- Oracle BI Publisher and OTBI
- Oracle Integration Cloud (OIC Gen 3)
- Oracle SQL and PL/SQL
- HCM Data Loader (HDL)
- REST and SOAP APIs
- JavaScript for OIC and VBCS

## Repository Structure
- `BI-Publisher/` — Data models, bursting queries and templates
- `SQL-PLSQL/` — Reusable SQL queries organized by Fusion module
- `OIC-Integrations/` — Integration patterns and error handling
- `JavaScript/` — OIC and VBCS reusable functions
- `HDL/` — Sample templates and data-loading examples
- `REST-APIs/` — API request and response examples
- `Documentation/` — Troubleshooting and technical notes

## Security
Use synthetic or anonymized examples only. Do not commit credentials, access tokens, personal information, confidential customer data or proprietary client code.

## Purpose
